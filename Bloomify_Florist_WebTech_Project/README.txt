BLOOMIFY — FLORIST SHOP WEB TECHNOLOGY PROJECT
==============================================

A complete two-stage florist shop website.

STAGE 1 — STATIC
----------------
Folder: Stage_1_Static
Open index.html directly in a browser.

Technology:
HTML5 + CSS3 + JavaScript

Features:
- Responsive florist landing page
- Flower product catalogue
- Category filters
- Add-to-cart
- Cart drawer and total
- Demo checkout
- Contact form validation
- Modern florist design

STAGE 2 — DYNAMIC
-----------------
Folder: Stage_2_Dynamic_PHP_MySQL

Technology:
PHP + MySQL + HTML/CSS/JavaScript

Features:
- Flower products loaded from MySQL
- PHP order form
- Orders saved to MySQL
- Contact enquiries saved to MySQL
- Prepared SQL statements
- Server-side validation
