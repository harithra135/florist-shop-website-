BLOOMIFY — FLORIST SHOP WEB TECHNOLOGY PROJECT
==============================================

A complete two-stage florist shop website.

STAGE 1 — STATIC
----------------
Folder: Stage_1_Static
Open index.html directly in a browser.

Technology:
HTML5 + CSS3 + JavaScript

Features:
- Responsive florist landing page
- Flower product catalogue
- Category filters
- Add-to-cart
- Cart drawer and total
- Demo checkout
- Contact form validation
- Modern florist design

STAGE 2 — DYNAMIC
-----------------
Folder: Stage_2_Dynamic_PHP_MySQL

Technology:
PHP + MySQL + HTML/CSS/JavaScript

Features:
- Flower products loaded from MySQL
- PHP order form
- Orders saved to MySQL
- Contact enquiries saved to MySQL
- Prepared SQL statements
- Server-side validation

XAMPP SETUP
-----------
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy Stage_2_Dynamic_PHP_MySQL to:
   C:\xampp\htdocs\Bloomify
4. Open http://localhost/phpmyadmin
5. Import:
   sql/bloomify.sql
6. If your MySQL root password is not empty, edit:
   includes/db.php
7. Open:
   http://localhost/Bloomify/
